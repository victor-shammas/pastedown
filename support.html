Getting started

How do I turn Markdown into rich text?

Copy the Markdown, then open Pastedown: it loads what you copied and shows the result. Choose Edit › Copy as Rich Text (⇧⌘C), or click the button in the toolbar, and paste into Notes, Mail, Pages, Word or Google Docs.

Can I edit the text first?

Yes. The left pane holds the Markdown source; the preview on the right follows as you type, and the two panes scroll together: scroll either one and the other follows. ⌘F finds text in the source. To hide the source and see only the result, choose View › Show Markdown Source (⌘\).

Can I convert the clipboard without loading it?

Yes. With Pastedown open and in front, Edit › Convert Clipboard to Rich Text (⌥⌘C) converts the Markdown on the clipboard in place, leaving the text in the window as it is.

Which Markdown does it understand?

GitHub-flavoured Markdown: headings, bold, italic and strikethrough, links, bulleted and numbered lists, task lists, tables, block quotations, code and code blocks, and horizontal rules. HTML inside the Markdown is kept where it is safe; scripts, styles and forms are removed.

The clipboard

When does Pastedown load the clipboard?

Once, when it opens. After that your text stays as it is. To load the clipboard again, choose Edit › Load Clipboard (⇧⌘V), which replaces the text in the window.

Can it follow the clipboard as I copy new things?

Yes: turn on Edit › Continuously Auto-Load Clipboard. Each time Pastedown comes to the front, it loads what you copied in the meantime. It never replaces text you have edited.

Can I stop it loading the clipboard when it opens?

Turn off Edit › On Launch, Load Clipboard. Both options are also in Pastedown › Settings.

It says the clipboard is large.

Pastedown doesn’t load more than about 200 KB of text by itself. Edit › Load Clipboard (⇧⌘V) loads it anyway.

I copied a reply from Claude Code in the terminal. What happens to its line breaks?

Text copied from a terminal arrives with its lines broken at the window’s width, padded with spaces, indented and marked with ⏺. Pastedown recognizes such a copy as it is loaded or pasted and repairs it: the lines of a paragraph are rejoined, the padding, indentation and markers go, a table drawn with box characters becomes a Markdown table, and commands are set as code. Markdown that didn’t come from a terminal is left as it is. To turn this off, choose Edit › Fix Line Breaks in Terminal Copies.

Can it fix the line breaks in other text, such as a column copied from a PDF?

Choose Edit › Fix Line Breaks (⇧⌘L): it rejoins the lines of each paragraph in the source pane and keeps the breaks between paragraphs. ⌘Z undoes it. It is meant for plain text; in Markdown that was written by hand it can also join lines you meant to keep apart.

Pasting

Why does the pasted text look different from the preview?

The preview is for reading. What goes on the clipboard is plainly styled, in a standard system font and size, whatever the preview’s settings. Headings, emphasis, lists, tables and links are kept. Apps that take only plain text get the Markdown itself.

What happens to task lists?

Checkboxes become the characters ☐ and ☑, which every app can show.

What happens to images?

Pastedown doesn’t fetch images from the web, so they aren’t shown in the preview. In what you copy, the image stays as a link for apps that can load it themselves, such as Mail or Google Docs; the others get the image’s description instead.

The formatting didn’t arrive in one app.

Some apps and text fields take only plain text. If an app that normally takes formatting gets it wrong, email me the Markdown and the name of the app.

Display

How do I change the font, the size or the colours?

In the View menu or in Pastedown › Settings: Zoom In and Zoom Out (⌘+, ⌘−; ⌘0 for the actual size), Wider and Narrower (⌘], ⌘[) or Fit to Window, which lets the text fill the preview, five typefaces, Justify Text (⌘J) and Dark Mode (⌘D). With Dark Mode off, Pastedown follows your Mac’s appearance, unless you have chosen Light in Settings. Zoom also enlarges the source. None of this changes what you copy.

Updates

How do I update Pastedown?

Choose Help › Check for Updates…: it opens the download page, where the version number of the latest release is shown. Download it and drag it into Applications, replacing the old copy. Pastedown doesn’t check for updates by itself, because it never connects to the internet.
